# Known messages of Khronos' Vulkan validation layers in the tests of the
# baselines in this directory, under `run --validation`, kept by hand.
#
# One line per pattern over test names, then a pattern over message IDs (a
# VUID or one of the layer's own names; `*` matches any run of characters
# in both), then optionally
#   issue=<n>  the mach9 issue that tracks the message
# A test is <exe>/<unit>/<key> of every leg, <key> is * for a unit that runs
# as a whole and `listing` for the listing of a unit's keys. `#` starts a
# comment, on a line of its own or after the notes:
#
#   d3d12/d3d12/test_draw VUID-vkCmdDraw-None-08600 issue=<n>
#
# A message an entry matches does not fail the run; any other does, error
# or warning.
