# Known messages of Khronos' Vulkan validation layers in the deqp-vk cases
# of the expected results in this directory, under `deqp-vk run
# --validation`, kept by hand.
#
# One line per pattern over case names, then a pattern over message IDs (a
# VUID or one of the layer's own names; `*` matches any run of characters
# in both), then optionally
#   issue=<n>  the mach9 issue that tracks the message
# A message a deqp-vk process reports before its first case belongs to
# `startup`. `#` starts a comment, on a line of its own or after the notes:
#
#   dEQP-VK.query_pool.statistics_query.* VUID-vkCmdBeginQuery-queryPool-01922 issue=<n>
#
# A message an entry matches does not fail the run; any other does, error
# or warning.

# The cases' own Vulkan usage, not that of KosmicKrisp or the loader:
