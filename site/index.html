Mach9

Play Windows games fast on your Apple silicon Mac. Wine is built in: drag Mach9 to Applications and play. There is nothing else to install or download.

Release notes · All releases

Its own Direct3D 9, written for Metal

Direct3D 9 games run on mtld3d, Mach9's own Direct3D 9 implementation. It draws straight on Metal, with no Vulkan or OpenGL layer in between. Direct3D 10, 11 and 12 games run fast too.

Mach9.app

  • Runs the Windows version of Steam, so Steam games install and start from there.
  • Runs 32-bit and 64-bit games without Rosetta.
  • Notarized, and updates itself.
  • Pick and start games from its Dock menu.

For launcher developers

The engine behind the app is a relocatable, signed Wine for games on Apple silicon Macs, made to be embedded in a launcher. The launcher configures it with rules that match processes, written with the compatdb-core crate.
