# Mach9 0.3.0

If you have Mach9 0.1.0, download [Mach9.dmg](https://github.com/athei/mach9/releases/latest/download/Mach9.dmg) and replace Mach9 in Applications with it: 0.1.0 cannot update itself.

## Games and programs

- A hidden part of a game's window no longer stays on screen over the rest of it, such as the Hangar preview in Condor 3's Free Flight planner.
- No One Lives Forever 2 and Tron 2.0 play their music.
- FL Studio 26 starts, and Skyrim no longer crashes from its raw input settings.
- 32-bit programs can use hardware breakpoints, which debuggers and some copy protection rely on.
- Includes the latest Wine, D3D12, D3D11, OpenGL and Vulkan fixes from upstream.

## On the Mac

- The Dock menu has a Website item that opens mach9.app.
- The Mach9.dmg window shows the version it installs.
