# Mach9 0.1.0

The first release.

Mach9 runs Windows games on Macs with Apple silicon. It carries its own Wine, built for arm64, and a launcher that starts the game you picked. FEX runs the x86 code of 32-bit and 64-bit games, so Rosetta is not needed. It needs macOS 26.4 or later.

## Getting started

- Move Mach9 to Applications and open it. With no game set up yet, it asks for a Windows executable. Leave "Save as new game" on to keep it as a game; turn it off to run something once, such as an installer.
- Keep Mach9 in the Dock. Right-click its icon to pick a game, add a new executable, open the config folder or check for updates.
- Each game is a small TOML file in `~/Library/Application Support/app.mach9/games/`, naming the executable and any arguments, environment variables and per-process settings it needs. `gamelauncher.toml` in `~/Library/Application Support/app.mach9/` holds the defaults every game starts from. Both files list every option they take.
- The output of the last launch is in `gamelauncher.log`, next to `gamelauncher.toml`.

## Good to know

- On a Retina display, games render at full resolution and Windows scales its UI to match. `retina_mode` and `dpi` change that per game.
- macOS turns on Game Mode while a game runs fullscreen.
- Mach9 checks for updates when you open it, at most once per check interval, and the Dock menu checks right away. Where it can, an update downloads as a patch against the version you have.
