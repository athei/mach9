# Mach9 0.2.0

## Games and programs

- Oblivion no longer hangs after it loads a save, and offers its Shadow Filtering and Shadows on Grass options.
- .NET programs packed into a single file no longer hang at start, and WPF programs no longer crash before their window appears.
- Fixed several hangs in programs that load, free or protect code while other threads run it.
- Programs that draw icons with the Windows fonts Segoe MDL2 Assets or Segoe Fluent Icons show the icons instead of boxes.

## Starting and quitting

- Steam and other programs that use the network start faster: each of their processes no longer waits 5 seconds to look up the Mac's own name.
- A program that connects to a server that does not answer now gives up after its own timeout, so a World of Warcraft client you quit soon after it starts no longer freezes for up to 75 seconds.

## On the Mac

- A game's Dock icon is no longer blocky.
- Shaking the mouse no longer enlarges the macOS pointer while it is over a game window.
