# Mach9 0.3.1

If you have Mach9 0.1.0, download [Mach9.dmg](https://github.com/athei/mach9/releases/latest/download/Mach9.dmg) and replace Mach9 in Applications with it: 0.1.0 cannot update itself.

## Games and programs

- Grand Theft Auto IV with Fusion Fix starts.
- D3D11 games no longer lose parts of the picture drawn with geometry shaders, such as the overlays in Condor 3.
- Half-Life 2 and Team Fortress 2 no longer show an "Illegal termination of worker thread" error when you quit.
- A program no longer stalls after it frees memory it ran code from.

## On the Mac

- After an update, the Dock menu shows the new version's items.
