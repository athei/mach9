# Mach9 0.4.0

If you have Mach9 0.1.0, download [Mach9.dmg](https://github.com/athei/mach9/releases/latest/download/Mach9.dmg) and replace Mach9 in Applications with it: 0.1.0 cannot update itself.

## Games and programs

- Fallout 3 and Fallout: New Vegas start.
- The legacy version of Counter-Strike: Global Offensive starts and loads maps.
- Force feedback joysticks work in games such as Condor 3.
- Unreal Engine 5 games such as DrainSim, started with -dx12, no longer crash while their main menu loads or quit with an out-of-memory error.
- D3D11 games that use stream output from geometry shaders draw correctly, and other D3D11 rendering errors and crashes are fixed.
- D3D9 games no longer show garbage in parts of a texture they did not fill.
- OpenGL, DirectDraw and D3D8 games show fewer striped shadows and flickering surfaces, and one OpenGL crash is fixed.
- Games that use x87 math, and programs that write or free their own code, run correctly in more cases.
- A game no longer hangs, with one CPU core at full load, when it closes a window.
- Programs built on .NET 5 or later start.

## On the Mac

- Minimizing a game while the Dock is hidden no longer freezes it for 8 seconds.
- A game no longer crashes after it switches to some display modes, such as 1366x768 or 1680x1050, and in modes shown with black bars the mouse stays inside the game's picture.
